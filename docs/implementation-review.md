# Approved portfolio implementation

The implementation follows the final approved portfolio preview, with the requested Arabic switch and refreshed logo mark.

| Area | Reference and implementation | Validation / intentional changes |
| --- | --- | --- |
| Copy | Ahmed Hamdi headline, three technical roles, original project names and corrected CV dates | No hero eyebrow added. Arabic translates UI/descriptions, while technical names remain English. |
| Typography | Georgia editorial headings, Arial body, Consolas labels | Arabic descriptions use system Arabic fonts and isolated Latin technical terms. |
| Palette | Warm cream `#f4f0e8`, navy `#081827`, coral `#e85a42` | Light and Dark preserve the same layout; theme choice persists. |
| Hero media | Two tilted project frames, flowing paths and pulsing points | Pairs rotate every 12 seconds, screenshots every 3 seconds; frames open the displayed project. Social icons and typewriter match requested additions. |
| Projects | Fixed 220px alternating rows, optional featured-first paired grid | Intrinsic image sizes cannot enlarge desktop rows. Mobile cards stack naturally. Only screenshots rotate; projects do not scroll horizontally. |
| Navigation | Compact desktop header and accessible mobile disclosure | Lucide icons, keyboard Escape handling, language/theme controls and a refreshed orbiting Layers mark. |
| Motion | One-time section reveal, progressive experience timeline, gentle interactions | Motion respects reduced-motion preferences and pauses automated screenshots during interaction/offscreen. |
| Contacts | Compact contact band and structured footer | WhatsApp floats 100px from the bottom. Email, CV, GitHub and LinkedIn use actual destinations. |

Browser review covered desktop, 390px mobile and 320px mobile, English/Arabic, Light/Dark, persistent settings, menu Escape, project layout selection, local images and dot controls. No horizontal text/card overflow was found in reviewed viewports. Images, icons and CV are local deployment assets.
